Token Radar ranks 40 pre-token DeFi protocols by implied value, scored from TVL, 7-day growth, age and category, with a live-token board set aside and a farm plan for each protocol.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```

Requires Node.js 22 or later. The build writes `out/board.json`, `out/data.js`, `out/dossier.json` and copies the dashboard to `out/dashboard`; open `out/dashboard/index.html` to view the board.
